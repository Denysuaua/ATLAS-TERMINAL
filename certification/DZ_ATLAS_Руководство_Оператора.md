# «Атлас» — руководство оператора стенда оптимизации

**Версия:** 1.0 (2026-09-30). Работа идёт через пульт; командная строка нужна только для однократной подготовки инструмента.

## 1. Однократно на инструмент

| Шаг | Что сделать | Результат |
|---|---|---|
| 1 | Выгрузить минутки из NinjaTrader индикатором `DZ_IND_BarExporter_S021` | CSV и манифест в `dz_export` |
| 2 | `DZ_DATA_Sanitizer.py clean`, затем `DZ_CERT_Data.py certify --symbol MGC` | `data_certified/MGC/` с сертификатом |
| 3 | `DZ_CERT_Instrument.py` | паспорт инструмента |
| 4 | В стратегии включить `[U04]` и запустить её один раз | `dz_export\hub_menu_schema.json` |

## 2. Каждый день — только пульт

1. **Двойной щелчок по `START_ATLAS_SERVICE.bat`.** Окно службы не закрывать, пока идут расчёты. Ключ лежит в `atlas_service_token.txt`.
2. **Открыть `atlas_dashboard.html`**, вкладка «Конфигуратор задач».
3. **Загрузить схему меню и граф** `DZ_OPT_Graph_DualBreakout.json`.
4. **Выбрать инструмент.** Пульт подставит символ сертифицированных данных и стартовые диапазоны стопа и трейлинга из профиля.
5. **Выбрать режим:**
   - «Разработчик» — отметить параметры, задать «от — до — шаг»;
   - «Умный: параметр» — один целевой параметр, связанные по графу добавятся сами, с причиной связи;
   - «Умный: вся стратегия» — выбрать гипотезу из графа.
6. **Проверить ограничения** — невозможные комбинации, например «безубыток дальше стопа», отбрасываются до запуска.
7. При необходимости включить **скользящую проверку вперёд** и задать годы.
8. **Ввести порт и ключ службы, нажать «В очередь службы».** Таблица под кнопкой каждые 3 секунды показывает состояние: в очереди, выполняется, готово, ошибка.
9. **Готово →** вкладка «Пресет»: загрузить `results\<задача>\summary.json`, сформировать пресет, положить его в `dz_export\presets` и указать в `[U05]`.

## 3. Как читать результат

| Показатель | Что значит | Решение |
|---|---|---|
| **Порог «случайного лучшего»** на пульте | Шарп, который даст лучший из N наборов без всякого преимущества | результат ниже порога — это шум |
| **Дефлированный Шарп (DSR)** | вероятность, что лучший Шарп выше ожидаемого максимума при нулевом преимуществе, с учётом **всех** испытаний проекта | ≥ 0,95 — преимущество доказано; ниже — нет |
| **PBO (CSCV)** | вероятность, что лучший на одной половине истории окажется хуже медианы на другой | ≤ 0,5 обязательно; ≤ 0,15 — для золота |
| **Плато против пика** | плато — лучший по среднему в окрестности ±1 шаг сетки; пик — одиночный максимум | выбирать плато; пик без плато — удача |
| **Эффективность проверки вперёд** | прибыль вне выборки в день / в выборке в день | около 1 — устойчиво; около 0 и ниже — подгонка |

**Каждое испытание повышает порог.** Широкая сетка и частые перезапуски делают доказательство преимущества дороже — это записывается в реестр и учитывается автоматически.

## 4. Если что-то не так

| Признак | Причина | Что сделать |
|---|---|---|
| «служба: …» под кнопкой | служба не запущена или неверен ключ | запустить `START_ATLAS_SERVICE.bat`, скопировать ключ из файла |
| Задача в состоянии «ошибка» с «нет сертифицированных данных» | инструмент не сертифицирован | раздел 1, шаг 2 |
| «сертификат данных … не прошёл проверку» | данные изменены после сертификации | сертифицировать заново; разобраться, кто изменил |
| Пульт не видит инструмент | в графе нет профиля | добавить профиль в `instrument_profiles` |
