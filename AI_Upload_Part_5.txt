# Лаборатория S021 — пояснительная записка

**Версия:** 1.0 (2026-10-01) · **Основа:** `hub_menu_schema.json` (221 настройка), `DZ_OPT_Graph_DualBreakout.json`, `DZ_LAB_Matrix_S021.json`.

## 1. Главное честно

**Взаимные корреляции модулей пока не выявлены — и утверждать их было бы выдумкой.** На момент записки выполнен один изолированный проход на двух месяцах данных; это проверка конвейера, а не результат. Корреляции появятся в аудите `DZ_LAB_Master_Audit.db` по мере прохода трёх методов, и только для параметров с исполнителем.

## 2. Из чего состоят 221 настройка

| Класс | Число | Что это | Как исследуется |
|---|---|---|---|
| Защитный | 41 | режим без ордеров, пульт, пресеты, визуализация, пул серий, слоты модулей, строки | **не оптимизируется**: перебор безопасности и устройства раздувает число испытаний |
| Структурный | 59 | переключатели и перечисления | как отдельные гипотезы «вкл/выкл», не перебором |
| Числовой | 121 | пороги, окна, тики | тремя проходами — **если есть исполнитель** |

**Исполнитель на ПК сегодня есть у 12 числовых параметров** — у тех, что связаны с эталоном пробоя через граф. Остальные числовые ждут исполнителя модулей на C#: до него они в матрице со статусом `NO_EXECUTOR`, а не «исследованы».

## 3. Известные связи — из графа, с причинами

| Параметр | Связан с | Почему |
|---|---|---|
| `stop_ticks` | `be_trigger_ticks` | безубыток на +15 при стопе 200 — это 0,075R; соотношение задаёт структурную долю прибыльных stop/(stop+trigger) |
| `be_trigger_ticks` | `be_offset_ticks` | отступ имеет смысл только относительно порога включения |
| `be_trigger_ticks` | `trail_morning_ticks` | трейлинг включается вместе с безубытком; трейлинг короче порога подтягивает стоп выше безубытка сразу |
| `be_trigger_ticks` | `trail_evening_ticks` | то же для вечера |
| `min_range_ticks` | `max_range_ticks` | границы одного окна допуска ширины базы |
| `max_range_ticks` | `stop_ticks` | уровень входа — граница базы; широкая база означает дальний противоположный край |
| `atr_fast` | `atr_slow` | NormVol — их отношение |
| `atr_fast` | `flat_threshold` | порог сравнивается с отношением, зависящим от обоих периодов |
| `atr_slow` | `flat_threshold` | то же |

Направление ребра задаёт порядок: ребёнок (`b`) не исследуется, пока родитель (`a`) не получил `VALIDATED`.

## 4. Протокол трёх проходов

| Проход | Что делает | Пройден, если |
|---|---|---|
| 1. Изолированный | сетка одного параметра, остальные — текущие значения стратегии | сырой лучший не дальше шага сетки от плато — иначе одиночный пик |
| 2. Связанный | параметр и его соседи по графу, с ограничениями «безубыток ближе стопа» и т. п. | сделок ≥ 150, PF ≥ 1,35, просадка не хуже −3 500, лучшее ушло от изолированного не больше 25% |
| 3. Проверка вперёд | окна 180 дней обучения и 45 дней проверки с шагом 30 | эффективность ≥ 0,60 и средняя PBO обучения ≤ 0,25 |

Пороги — значения по умолчанию из ТЗ, они записаны в матрице у каждого параметра и меняются там.

## 5. Бюджет испытаний

Каждое испытание повышает порог «случайного лучшего» для всего проекта. Перед каждым запуском оболочка считает, каким станет этот порог; выше бюджета (по умолчанию 4σ) запуск без `--force` не выполняется. Исследовать все параметры подряд широкими сетками — верный способ не доказать ни одного.

## 6. Что расширит лабораторию

1. **Исполнитель модулей на C#** (спецификация B3–B5): даст исполнителя числовым параметрам ядра, Лоренца, Хёрста, массы, Калмана и рычага.
2. **Структурные гипотезы** — отдельный режим «вкл/выкл модуль» с той же проверкой вперёд.
3. **Связи между модулями** выявляются только так: связанный проход по параметрам двух модулей и сравнение с изолированными. Тогда записка получит раздел найденных корреляций — с прогонами в аудите.

## Правила сетки

| Единица | Правило | Почему |
|---|---|---|
| тики | целые, ×0,5…×2 от текущего | цена дискретна, шаг — тик |
| окна и периоды в барах | геометрическая сетка ×0,5…×2 | у окна 20 и окна 200 одинаковая относительная чувствительность |
| доли 0–1 | шаг 0,05, ±0,15 от текущего | разрешение, различимое на истории |
| множители | ±50% от текущего | порядок величины, а не подгонка знака после запятой |
| параметры эталона пробоя | сетка графа | уже обоснована исследованием |

Сетка никогда не выходит за пределы `[Range]` свойства в коде.

    s = importlib.util.spec_from_file_location(name, os.path.join(HERE, fn)); m = importlib.util.module_from_spec(s); s.loader.exec_module(m); return m


def kweights(kernel, h):
    u = np.arange(h) / h
    if kernel == "Triangular": return np.where(u < 1, 1 - u, 0.0)
    if kernel == "Tricube": return np.where(u < 1, (1 - u ** 3) ** 3, 0.0)
    if kernel == "Cosine": return np.where(u < 1, np.cos(np.pi * 0.5 * u), 0.0)
    if kernel == "Gaussian": return np.exp(-0.5 * (3.0 * u) ** 2)
    return np.where(u < 1, 1 - u * u, 0.0)


def fit_all(c, kernel, h):
    """Векторно по всем барам: α, β (цена/бар), t локальной прямой и α Надарая–Ватсона; y[i] = c[t−i], x = −i."""
    n = len(c); w = kweights(kernel, h); x = -np.arange(h, dtype=float)
    Y = sliding_window_view(c, h)[:, ::-1]          # строка t: c[t], c[t−1], … c[t−h+1]
    s0 = w.sum(); s1 = (w * x).sum(); s2 = (w * x * x).sum(); d = s0 * s2 - s1 * s1
    t0 = Y @ w; t1 = Y @ (w * x); yy = (Y * Y) @ w
    alpha = np.full(n, np.nan); beta = np.full(n, np.nan); tst = np.full(n, np.nan); nw = np.full(n, np.nan)
    nw[h - 1:] = t0 / s0
    if d <= 1e-12 * s0 * s0:
        alpha[h - 1:] = t0 / s0; return alpha, beta, tst, nw
    a = (t0 * s2 - t1 * s1) / d; b = (s0 * t1 - s1 * t0) / d
    rss = yy - 2 * a * t0 - 2 * b * t1 + a * a * s0 + 2 * a * b * s1 + b * b * s2
    cc = ((w * (s0 * x - s1) / d) ** 2).sum(); se = np.sqrt(np.maximum(0.0, rss / s0 * cc))
    alpha[h - 1:] = a; beta[h - 1:] = b; tst[h - 1:] = np.where(se > 0, b / se, 0.0)
    return alpha, beta, tst, nw


def tr_ratio(h, l, c):
    tr = np.empty(len(c)); tr[0] = h[0] - l[0]
    tr[1:] = np.maximum(h[1:] - l[1:], np.maximum(np.abs(h[1:] - c[:-1]), np.abs(l[1:] - c[:-1])))
    s = pd.Series(tr); a5 = s.rolling(5).mean(); a20 = s.rolling(20).mean()
    return (a20 / a5).to_numpy(float)

  ХУДШИЙ ВАРИАНТ там, где руководство правила не раскрывает:
    лимит      исполняется только при ПРОБОЕ цены, касания мало.
    путь бара  неблагоприятное событие внутри свечи наступает раньше благоприятного:
               сначала движение против позиции; при ожидании входа — вход, затем к стопу.
    бар входа  стоп, выставленный входом, действует сразу; цель — со следующего бара.

  Каждый бар, где путь изменил результат, записывается в журнал неоднозначностей
  с разницей капитала между путями: это цена незнания внутрибарной истории.

class WorstCaseEngine(E.Engine):

    # ---------- состояние бара: снимок и восстановление ----------
    def _snap(self):
        return (copy.deepcopy(self.pos), [copy.copy(w) for w in self.working],
                len(self.trades), len(self.ledger), self._oid)

    def _restore(self, s):
        self.pos = copy.deepcopy(s[0]); self.working = [copy.copy(w) for w in s[1]]
        del self.trades[s[2]:]; del self.ledger[s[3]:]; self._oid = s[4]

    def _equity(self, k, n0):
        realized = sum(t["NetCurrency"] for t in self.trades[n0:])
        unreal = (self.c[k] - self.pos.avg) * self.pos.side * self.pos.qty * self.pv if self.pos.side else 0.0
        return realized + unreal

    # ---------- один путь бара ----------
    def _run_path(self, k, up, same_bar_exit=True):
        o, h, l, c = self.o[k], self.h[k], self.l[k], self.c[k]
        segs = [(o, h), (h, l), (l, c)] if up else [(o, l), (l, h), (h, c)]
        for si, (a, b) in enumerate(segs):
            cur = a
            while True:
                # Исполняется ордер, до которого цена доходит ПЕРВЫМ: рыночный — в начале
                # отрезка; стоп и лимит — по расстоянию от текущей точки пути. При равенстве —
                # неблагоприятный первым. Прежде ордера брались в порядке списка, и стоп мог
                # исполниться раньше рыночного разворота, стоявшего на открытии.
                best = None
                for od in self.working:
                    if not od.is_entry and self.pos.side == 0:
                        continue
                    if not od.is_entry and od.submitted_bar == k and od.kind == "limit":
                        continue          # цель, выставленная входом этого бара: благоприятное не засчитывается
                    px = self._fill_price(od, cur, b, k, si == 0 and cur == a)
                    if px is None:
                        continue
                    if od.kind == "market":
                        dist = -1.0
                    elif od.kind == "stop" and ((od.side > 0 and cur >= od.price) or (od.side < 0 and cur <= od.price)):
                        dist = 0.0
                    else:
                        dist = abs(od.price - cur)
                    pri = 0 if od.kind == "market" else (1 if (not od.is_entry and od.kind == "stop") else 2)
                    if best is None or (dist, pri) < best[0]:
                        best = ((dist, pri), od, px)
                if best is None:
                    break
                _, od, px = best
                self.working.remove(od)
                self._execute(od, px, k)     # вход ставит стоп и цель — они действуют сразу
                # Следующий ордер отрезка считается от точки исполнения, но не за пределами отрезка.
                cur = min(max(px, min(a, b)), max(a, b))

    # ---------- бар: неблагоприятное событие внутри свечи — раньше благоприятного ----------
    def _process_bar(self, k):
        """
        Худший вариант определяется по СОБЫТИЯМ, а не по капиталу на закрытии бара.
        Критерий по капиталу близорук: отказ от выхода на баре входа делает капитал на
        закрытии хуже, но спасает сделку на следующем баре — проверка это показала.
          позиция длинная на начало бара  → путь O→L→H→C: сначала против позиции
          позиция короткая                → O→H→L→C
          вне рынка, ждёт вход на покупку → O→H→L→C: вход, затем вниз к стопу
          вне рынка, ждёт вход на продажу → O→L→H→C
          ждёт входы в обе стороны        → оба пути, принимается худший капитал на закрытии
        Стоп, выставленный входом, действует уже на баре входа; цель — нет.
        """
        if self.pos.side == 0 and not self.working:
            return
        side = self.pos.side
        mk = [w for w in self.working if w.is_entry and w.kind == "market"]
        if mk:
            side = mk[0].side                          # рыночный вход исполнится по открытию
        if side > 0:
            paths = [False]
        elif side < 0:
            paths = [True]
        else:
            sides = {w.side for w in self.working if w.is_entry}
            paths = [True] if sides == {1} else [False] if sides == {-1} else [True, False]

        s0 = self._snap(); n0 = len(self.trades)
        res = {}
        for up in (True, False):                       # оба пути — для журнала цены незнания
            self._restore(s0); self._run_path(k, up); res[up] = (self._equity(k, n0), self._snap())
        pick = min(paths, key=lambda u: res[u][0])
        self._restore(res[pick][1])
        if abs(res[True][0] - res[False][0]) > 1e-9:
            self.ledger.append({"bar_utc": str(self.t[k]), "assumed_up_first": pick,
                                "equity_assumed": round(res[pick][0], 2), "equity_other": round(res[not pick][0], 2),
                                "cost_of_ignorance": round(abs(res[True][0] - res[False][0]), 2)})

def nt_summary(tr, bars):
    if len(tr) == 0:
        return {"Всего сделок": 0}
    net = tr.NetCurrency.to_numpy(float); gross = tr.GrossCurrency.to_numpy(float)
    win, loss, even = net[net > 0], net[net < 0], net[net == 0]
    eq = np.cumsum(net); dd = float((np.maximum.accumulate(np.r_[0, eq]) - np.r_[0, eq]).max())
    cw = cl = mw = ml = 0
    for v in net:
        cw, cl = (cw + 1, 0) if v > 0 else ((0, cl + 1) if v < 0 else (0, 0))
        mw, ml = max(mw, cw), max(ml, cl)
    days = max(1.0, (bars.index[-1] - bars.index[0]).total_seconds() / 86400)
    gp, gl = float(gross[gross > 0].sum()), float(gross[gross < 0].sum())
    return {
        "Чистая прибыль": round(float(net.sum()), 2),
        "Валовая прибыль (до комиссии)": round(gp, 2),
        "Валовой убыток (до комиссии)": round(gl, 2),
        "Комиссия": round(float(tr.Commission.sum()), 2),
        "Фактор прибыли (по валовым)": round(gp / -gl, 3) if gl < 0 else None,
        "Макс. просадка (по закрытым сделкам)": round(-dd, 2),
        "Всего сделок": int(len(net)),
        "Процент прибыльных": round(100 * len(win) / len(net), 2),
        "Прибыльных / убыточных / в ноль": f"{len(win)} / {len(loss)} / {len(even)}",
        "Средняя сделка": round(float(net.mean()), 2),
        "Средняя прибыльная": round(float(win.mean()), 2) if len(win) else None,
        "Средняя убыточная": round(float(loss.mean()), 2) if len(loss) else None,
        "Отношение ср. прибыльной к ср. убыточной": round(float(win.mean() / -loss.mean()), 3) if len(win) and len(loss) else None,
        "Макс. прибыльных подряд": mw, "Макс. убыточных подряд": ml,
        "Крупнейшая прибыльная": round(float(net.max()), 2), "Крупнейшая убыточная": round(float(net.min()), 2),
        "Сделок в день": round(len(net) / days, 3),
        "Средняя длительность, баров": round(float(tr.BarsHeld.mean()), 1),
        "Среднее MAE, тиков": round(float(tr.MAE_Ticks.mean()), 2),
        "Среднее MFE, тиков": round(float(tr.MFE_Ticks.mean()), 2),
    }

ЭТАЛОН ПРАВИЛ — руководство NinjaTrader 8, раздел 12.4.5 «Historical Order Backfill Logic»:
  «The algorithm fills historical orders using the same set of logic in both scenarios»
  (Strategy Analyzer и исторические ордера живой стратегии). Бар проходится тремя отрезками:
  открытие → первый экстремум → второй экстремум → закрытие, в зависимости от того,
  «moved up first» или «moved down first». Для каждого отрезка:

                с проскальзыванием;
    лимит     — «set the fill price to the current order's Limit price»; с включённым
                «Fill Limit Orders on Touch» при касании — по открытию бара.

  правило «куда бар двинулся сначала»        --first-move closer | closeopen
  требуется ли пробой лимита или хватает касания --limit through | touch
  исполняются ли выходы на баре входа        сейчас — нет; проверяется калибровкой
Калибровка — командой calibrate на выгрузке сделок Strategy Analyzer.

СТРАТЕГИИ — классы с методом on_bar_update() и API управляемого подхода NinjaScript.

def _load_mod(path, name):
    spec = importlib.util.spec_from_file_location(name, path)
    m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m); return m


def detect_source_tz(naive, candidates=("America/Chicago", "UTC", "America/New_York", "Europe/Berlin")):
    """
    ЭКСПЕРИМЕНТ. Пояс исходных меток по подписи рынка CME: в поясе Чикаго бары 17:00–17:01
    (открытие Globex) есть каждый будний вечер, а в перерыве 16:15–16:45 баров нет.
    Выбирается пояс, где эта подпись выражена сильнее всего. Для рынков вне CME — задать явно.
    """
    best, score_best, rep = None, -1e9, {}
    for tz in candidates:
        loc = pd.DatetimeIndex(naive).tz_localize(tz, ambiguous="NaT", nonexistent="NaT").dropna()
        ct = loc.tz_convert("America/Chicago")
        wd = ct.dayofweek <= 3; hm = ct.hour * 100 + ct.minute
        reopen = int(((hm >= 1700) & (hm <= 1701) & wd).sum())
        halt = int(((hm >= 1615) & (hm < 1645) & wd).sum())
        s = reopen - 10 * halt
        rep[tz] = {"reopen_bars": reopen, "halt_bars": halt}
        if s > score_best:
            best, score_best = tz, s
    return best, rep


def load_bars(path, src_tz, bar_label, ref_path):
    """
    Любой из форматов: .npz/.parquet из DZ_DATA_Sanitizer; CSV с заголовком или без, с
    разделителем «;», «,» или табуляцией, с датой и временем в одном поле или в двух —
    включая формат выгрузки NinjaTrader «yyyyMMdd HHmmss;O;H;L;C;V». Разбор даты — функции
    эталона DZ_BT (по монотонности времени, без dayfirst наугад).
    Возвращает бары с индексом UTC по времени ОТКРЫТИЯ бара, столбцы o h l c v.
    """
    if path.endswith((".npz", ".parquet")):
        san = _load_mod(os.path.join(os.path.dirname(ref_path) or ".", "DZ_DATA_Sanitizer.py"), "dz_san")
        return san.load_clean(path), {"source": "cache"}
    ref = _load_mod(ref_path, "dz_ref")
    stamp, df = ref.read_raw(path)
    fmt, _ = ref.detect_date_format(stamp, "auto")
    naive = pd.to_datetime(stamp, format=fmt, errors="coerce")
    num = lambda c: pd.to_numeric(df[c], errors="coerce") if c in df.columns else pd.Series(0.0, index=df.index)
    d = pd.DataFrame({"ts": naive, "o": num("Open"), "h": num("High"), "l": num("Low"), "c": num("Close"), "v": num("Volume")}).dropna(subset=["ts", "o", "h", "l", "c"])
    info = {"date_format": fmt}
    if src_tz == "auto":
        src_tz, info["tz_detection"] = detect_source_tz(d.ts)
    loc = pd.DatetimeIndex(d.ts).tz_localize(src_tz, ambiguous="NaT", nonexistent="NaT")
    d = d[~loc.isna()]; loc = loc[~loc.isna()]
    if bar_label == "auto":
        bar_label, info["label_evidence"] = ref.detect_bar_label(loc.tz_convert("America/Chicago").tz_localize(None), "auto")
    utc = loc.tz_convert("UTC") - (pd.Timedelta(minutes=1) if bar_label == "close" else pd.Timedelta(0))
    out = d.drop(columns="ts").set_index(pd.DatetimeIndex(utc, name="t")).sort_index()
    out = out[~out.index.duplicated(keep="first")]
    info.update({"src_tz": src_tz, "bar_label": bar_label, "bars": len(out)})
    return out, info

class Strategy:
    """База стратегии. Методы повторяют имена NinjaScript; вызываются из on_bar_update()."""
    params = {}

    def __init__(self, **kw):
        self.p = dict(self.params); self.p.update(kw)

    # --- доступ к барам: i баров назад, как Close[i] ---
    def Close(self, i=0): return self._e.c[self._e.k - i]
    def Open(self, i=0): return self._e.o[self._e.k - i]
    def High(self, i=0): return self._e.h[self._e.k - i]
    def Low(self, i=0): return self._e.l[self._e.k - i]
    @property
    def CurrentBar(self): return self._e.k
    @property
    def Position(self): return self._e.pos

    def SMA(self, period, i=0):
        k = self._e.k - i
        return float(np.mean(self._e.c[k - period + 1:k + 1])) if k >= period - 1 else float("nan")

    # --- ордера ---
    def EnterLong(self, qty=1, name="Long"): self._e.submit(name, +1, "market", qty, is_entry=True)
    def EnterShort(self, qty=1, name="Short"): self._e.submit(name, -1, "market", qty, is_entry=True)
    def EnterLongStopMarket(self, qty, price, name="Long"): self._e.submit(name, +1, "stop", qty, price, True)
    def EnterShortStopMarket(self, qty, price, name="Short"): self._e.submit(name, -1, "stop", qty, price, True)
    def EnterLongLimit(self, qty, price, name="Long"): self._e.submit(name, +1, "limit", qty, price, True)
    def EnterShortLimit(self, qty, price, name="Short"): self._e.submit(name, -1, "limit", qty, price, True)
    # Выходы: qty = 0 — вся позиция; иначе частичный выход, остаток позиции живёт дальше.
    def ExitLong(self, qty=0, name="Exit"): self._e.submit(name, -1, "market", qty, is_entry=False)
    def ExitShort(self, qty=0, name="Exit"): self._e.submit(name, +1, "market", qty, is_entry=False)
    def ExitLongLimit(self, qty, price, name="Exit limit"): self._e.submit(name, -1, "limit", qty, price, False)
    def ExitShortLimit(self, qty, price, name="Exit limit"): self._e.submit(name, +1, "limit", qty, price, False)
    def ExitLongStopMarket(self, qty, price, name="Exit stop"): self._e.submit(name, -1, "stop", qty, price, False)
    def ExitShortStopMarket(self, qty, price, name="Exit stop"): self._e.submit(name, +1, "stop", qty, price, False)
    def SetStopLoss(self, ticks=None, price=None): self._e.stop_spec = ("ticks", ticks) if ticks else ("price", price)
    def SetProfitTarget(self, ticks=None, price=None): self._e.target_spec = ("ticks", ticks) if ticks else ("price", price)

    def on_bar_update(self):
        raise NotImplementedError


class SampleMACrossOver(Strategy):
    """
    Копия встроенной @SampleMACrossOver NinjaTrader:
      if (CrossAbove(SMA(Fast), SMA(Slow), 1)) EnterLong();
      else if (CrossBelow(SMA(Fast), SMA(Slow), 1)) EnterShort();
    Проверяйте в Strategy Analyzer с теми же Fast и Slow — это первый тест паритета.
    """
    params = {"Fast": 10, "Slow": 25, "StopTicks": 0, "TargetTicks": 0}

    def on_bar_update(self):
        if self.CurrentBar < self.p["Slow"]:
            return
        if self.p["StopTicks"]: self.SetStopLoss(ticks=self.p["StopTicks"])
        if self.p["TargetTicks"]: self.SetProfitTarget(ticks=self.p["TargetTicks"])
        f0, s0 = self.SMA(self.p["Fast"]), self.SMA(self.p["Slow"])
        f1, s1 = self.SMA(self.p["Fast"], 1), self.SMA(self.p["Slow"], 1)
        if f1 <= s1 and f0 > s0:
            self.EnterLong(name="MA cross up")
        elif f1 >= s1 and f0 < s0:
            self.EnterShort(name="MA cross down")

# ======================================================================================
# 4. ДВИЖОК: исторический алгоритм исполнения NinjaTrader

@dataclass
class SimConfig:
    qty: int = 1
    slippage_ticks: float = 0.0
    first_move: str = "closer"     # closer — ближний к открытию экстремум первым; closeopen — по знаку C−O
    limit: str = "through"         # through — лимит требует пробоя; touch — хватает касания
    exit_on_session_close: bool = True
    entries_per_direction: int = 1


class Engine:
    def __init__(self, bars, inst, strategy, cfg):
        self.b, self.inst, self.s, self.cfg = bars, inst, strategy, cfg
        self.o, self.h, self.l, self.c = (bars[x].to_numpy(float) for x in "ohlc")
        self.t = bars.index
        self.tick = inst["tick"]
        self.pv = inst["point_value"]
        self.comm = inst.get("commission_per_side", 0.0)
        self.working, self.trades, self.ledger = [], [], []
        self.pos = Position()
        self.stop_spec = self.target_spec = None
        self.k, self._oid = 0, 0
        loc = self.t.tz_convert(inst["tz"])
        close_hm = int(inst["session_close"].replace(":", ""))
        # Время — явно в наносекундах: урок дефекта Д-23.
        tns = pd.DatetimeIndex(self.t).as_unit("ns").asi8 if hasattr(self.t, "as_unit") else self.t.asi8
        nxt = np.r_[tns[1:], tns[-1] + 10 ** 12]
        gap = (nxt - tns) > 30 * 60 * 10 ** 9
        end_hm = (loc + pd.Timedelta(minutes=1)).hour * 100 + (loc + pd.Timedelta(minutes=1)).minute
        # Последний бар сессии: следующий бар далеко либо бар заканчивается на закрытии сессии.
        self.session_last = gap | (end_hm == close_hm)
        strategy._e = self

    # --- подача ордеров из стратегии ---
    def submit(self, name, side, kind, qty, price=float("nan"), is_entry=True):
        # Повторная подача того же ордера обновляет его, а не плодит новый.
        same = [w for w in self.working if w.is_entry == is_entry and w.side == side and w.kind == kind
                and (is_entry or w.name == name) and w.touched_bar < 10 ** 12]
        if same:
            same[0].price, same[0].touched_bar = price, self.k
            if qty:
                same[0].qty = qty
            return
        if is_entry and self.pos.side == side and self.pos.qty >= self.cfg.entries_per_direction * max(1, qty or self.cfg.qty):
            return                                  # EntriesPerDirection
        self._oid += 1
        # Для выхода qty = 0 означает «вся позиция»; прежде подставлялся объём по умолчанию,
        # и ExitLong() на позиции в 3 контракта закрывал только один.
        self.working.append(Order(self._oid, name, side, kind, (qty or self.cfg.qty) if is_entry else qty, price,
                                  is_entry, submitted_bar=self.k, touched_bar=self.k))

    # --- модель пути внутри бара ---
    def _path(self, k):
        o, h, l, c = self.o[k], self.h[k], self.l[k], self.c[k]
        up = (h - o) <= (o - l) if self.cfg.first_move == "closer" else c >= o
        return ([(o, h), (h, l), (l, c)] if up else [(o, l), (l, h), (h, c)]), up

    def _fill_price(self, od, a, b, k, first_seg):
        lo, hi = min(a, b), max(a, b)
        if od.kind == "market":
            px = a if first_seg else None
            if px is None:
                return None
        elif od.kind == "stop":
            if od.side > 0:
                px = a if a >= od.price else (od.price if hi >= od.price else None)
            else:
                px = a if a <= od.price else (od.price if lo <= od.price else None)
            if px is None:
                return None
        else:                                        # limit
            hit = (lo <= od.price if self.cfg.limit == "touch" else lo < od.price) if od.side > 0 else \
                  (hi >= od.price if self.cfg.limit == "touch" else hi > od.price)
            if not hit:
                return None
            return od.price                          # руководство: «the current order's Limit price»
        # проскальзывание — рыночным и стоповым, не выходя за пределы бара
        slip = self.cfg.slippage_ticks * self.tick * od.side
        return min(max(px + slip, self.l[k]), self.h[k])

    def _process_bar(self, k):
        segs, up = self._path(k)
        live = [w for w in self.working]
        filled_ids = set()
        for si, (a, b) in enumerate(segs):
            # Очерёдность по пути цены: рыночный — в начале отрезка, стоп и лимит — по
            # расстоянию от начала отрезка. Прежде — в порядке списка, и стоп мог исполниться
            # раньше рыночного разворота на открытии.
            ordered = sorted(live, key=lambda od: -1.0 if od.kind == "market" else (
                0.0 if od.kind == "stop" and ((od.side > 0 and a >= od.price) or (od.side < 0 and a <= od.price))
                else abs(od.price - a)))
            for od in ordered:
                if od.oid in filled_ids:
                    continue
                if od.is_entry is False and self.pos.side == 0:
                    continue
                px = self._fill_price(od, a, b, k, si == 0)
                if px is None:
                    continue
                filled_ids.add(od.oid)
                if si > 0 and od.kind != "market":
                    self.ledger.append({"bar": str(self.t[k]), "order": od.name, "segment": si, "moved_up_first": up})
                self._execute(od, px, k)
        self.working = [w for w in self.working if w.oid not in filled_ids]

    def _execute(self, od, px, k):
        if od.is_entry:
            if self.pos.side == -od.side:            # разворот: сначала закрыть
                self._close(px, k, "Close position")
            if self.pos.side == 0:
                self.pos = Position(od.side, od.qty, px, od.name, self.t[k], k, px, px)
                self._arm_exits(k)
        else:
            if self.pos.side != 0 and od.side == -self.pos.side:
                self._reduce(px, k, od.name, od.qty)

    def _arm_exits(self, k):
        """Стоп и цель выставляются от цены исполнения, как SetStopLoss/SetProfitTarget в тиках."""
        self.working = [w for w in self.working if w.is_entry]
        side, avg = self.pos.side, self.pos.avg
        for spec, kind, nm in ((self.stop_spec, "stop", "Stop loss"), (self.target_spec, "limit", "Profit target")):
            if not spec:
                continue
            mode, v = spec
            if mode == "ticks":
                price = avg - side * v * self.tick if kind == "stop" else avg + side * v * self.tick
            else:
                price = v
            self._oid += 1
            self.working.append(Order(self._oid, nm, -side, kind, self.pos.qty, price, False,
                                      submitted_bar=k, touched_bar=10 ** 12))

    def _close(self, px, k, reason):
        self._reduce(px, k, reason, 0)

    def _reduce(self, px, k, reason, qty):
        """
        Выход объёмом qty (0 — вся позиция). Четыре действия, и все обязательны:
          1. запись сделки на ВЫШЕДШИЙ объём — так Strategy Analyzer показывает частичные
             исполнения отдельными строками;
          2. уменьшение объёма позиции; средняя цена остатка НЕ меняется;
          3. защитные ордера — на объём остатка, иначе стоп закрыл бы больше, чем осталось;
          4. при нулевом остатке — сброс позиции и снятие всех ордеров выхода.
        """
        p = self.pos
        q = p.qty if (not qty or qty >= p.qty) else qty
        gross = (px - p.avg) * p.side * q * self.pv
        comm = 2 * self.comm * q
        self.trades.append({
            "EntryTimeUTC": str(p.entry_time), "ExitTimeUTC": str(self.t[k]), "Direction": p.side, "Qty": q,
            "EntryPrice": p.avg, "ExitPrice": px, "EntryName": p.name, "ExitName": reason,
            "GrossCurrency": round(gross, 2), "Commission": round(comm, 2), "NetCurrency": round(gross - comm, 2),
            "GrossTicks": round((px - p.avg) * p.side / self.tick, 2),
            "MAE_Ticks": round(max(0.0, (p.avg - p.lo) if p.side > 0 else (p.hi - p.avg)) / self.tick, 1),
            "MFE_Ticks": round(max(0.0, (p.hi - p.avg) if p.side > 0 else (p.avg - p.lo)) / self.tick, 1),
            "BarsHeld": k - p.entry_bar})
        p.qty -= q
        if p.qty <= 0:
            self.working = [w for w in self.working if w.is_entry]
            self.pos = Position()
        else:
            for w in self.working:
                if not w.is_entry and w.touched_bar >= 10 ** 12:
                    w.qty = p.qty

    def run(self):
        n = len(self.c)
        for k in range(n):
            self.k = k
            # Ордера, не подтверждённые на прошлом баре, снимаются (isLiveUntilCancelled = false).
            # Входы и выходы стратегии, не подтверждённые на прошлом баре, снимаются
            # (isLiveUntilCancelled = false). Защитные ордера помечены как вечные.
            self.working = [w for w in self.working if w.touched_bar >= k - 1]
            # Выходы, выставленные при входе на этом баре, в обработку этого бара не попадают:
            # набор ордеров фиксируется на начало бара. Исполнение выхода на баре входа не
            # моделируется — это предположение, проверяемое калибровкой.
            self._process_bar(k)
            if self.pos.side != 0:
                self.pos.hi = max(self.pos.hi, self.h[k]); self.pos.lo = min(self.pos.lo, self.l[k])
            if self.cfg.exit_on_session_close and self.pos.side != 0 and self.session_last[k]:
                self._close(self.c[k], k, "Exit on session close")
            self.s.on_bar_update()
        if self.pos.side != 0:
            self._close(self.c[-1], n - 1, "Data end")
        return pd.DataFrame(self.trades)

def perf(tr):
    if len(tr) == 0:
        return {"Trades": 0}
    net = tr.NetCurrency.to_numpy(float); w, l = net[net > 0], net[net < 0]
    eq = np.cumsum(net); dd = float((np.maximum.accumulate(np.r_[0, eq]) - np.r_[0, eq]).max())
    return {"Trades": len(net), "NetProfit": round(float(net.sum()), 2), "GrossProfit": round(float(w.sum()), 2),
            "GrossLoss": round(float(l.sum()), 2), "Commission": round(float(tr.Commission.sum()), 2),
            "ProfitFactor": round(float(w.sum() / -l.sum()), 3) if len(l) else None, "MaxDrawdown": round(-dd, 2),
            "WinRatePct": round(100 * len(w) / len(net), 2)}


def apply_task(a, ap):
    """
    Файл задачи Excel: значения ячеек → параметры запуска. Явно заданный ключ командной
    строки имеет приоритет над файлом. Неизвестные ключи сообщаются, а не пропускаются молча.
    """
    if not getattr(a, "task", None):
        return a
    task = json.load(open(a.task, encoding="utf-8"))
    unknown = []
    for k, v in task.items():
        key = k.replace("-", "_")
        if not hasattr(a, key):
            unknown.append(k); continue
        if getattr(a, key) == ap.get_default(key):
            setattr(a, key, json.dumps(v, ensure_ascii=False) if key == "params" and not isinstance(v, str) else v)
    if unknown:
        print(f"ВНИМАНИЕ: в задаче неизвестные ключи {unknown} — проигнорированы")
    return a


def run_once(a, bars, inst, **over):
    cfg = SimConfig(qty=a.qty, slippage_ticks=a.slippage, first_move=over.get("first_move", a.first_move),
                    limit=over.get("limit", a.limit),
                    exit_on_session_close=not a.no_session_exit)
    params = json.loads(a.params) if a.params else {}
    strat = STRATEGIES[a.strategy](**params)
    eng = Engine(bars, inst, strat, cfg)
    return eng.run(), eng.ledger

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
==========================================================================================
DZ_OPT_WFA.py — скользящая проверка вперёд (walk-forward), v1.0 (2026-09-28)

Сам ничего не считает: для каждого окна вызывает DZ_OPT_Engine_S021.py так же, как оператор.
  1. обучение  — задача плана на периоде train: оптимизатор выбирает лучший набор;
  2. проверка  — тот же набор, одно испытание, на периоде test, которого обучение не видело.
Каждый запуск записывается оптимизатором в реестр испытаний — проверка вперёд не бесплатна.

ПЛАН (формирует конфигуратор пульта):
  {"plan": "DZ-WFA-v1", "plan_id": "...", "task": {...задача без периода...},
   "windows": [{"train": ["2020-01-01", "2023-01-01"], "test": ["2023-01-01", "2024-01-01"]}, ...]}
Конец периода не включается: окна не делят ни одного бара.

ИТОГ — results/<plan_id>_wfa.csv и .json: по окнам — результат обучения и проверки;
  в целом — сумма вне выборки, доля прибыльных окон, эффективность проверки вперёд
  (прибыль вне выборки в день / прибыль в выборке в день). Около 1 — устойчиво; около 0 и
  ниже — параметры подогнаны под историю.

  python DZ_OPT_WFA.py --plan wfa_plan.json [--workers 0]
==========================================================================================
"""
import argparse, copy, json, os, subprocess, sys
import pandas as pd

VERSION = "DZ_OPT_WFA-v1.0 (2026-09-28)"
HERE = os.path.dirname(os.path.abspath(__file__))


def bdays(a, b):
    return max(1, len(pd.bdate_range(a, pd.Timestamp(b) - pd.Timedelta(days=1))))


def run(task, results, workers, graph):
    os.makedirs(os.path.join(results, "_wfa_tasks"), exist_ok=True)
    path = os.path.join(results, "_wfa_tasks", task["task_id"] + ".json")
    json.dump(task, open(path, "w", encoding="utf-8"), ensure_ascii=False, indent=2)
    cmd = [sys.executable, os.path.join(HERE, "DZ_OPT_Engine_S021.py"), "run", "--task", path, "--results", results,
           "--workers", str(workers), "--graph", graph, "--ref", os.path.join(HERE, "DZ_BT_DualBreakout_S021.py")]
    r = subprocess.run(cmd, capture_output=True, text=True)
    if r.returncode != 0:
        sys.exit(f"ОТКАЗ: оптимизатор не выполнил {task['task_id']}:\n{r.stderr[-1500:]}")
    return json.load(open(os.path.join(results, task["task_id"], "summary.json"), encoding="utf-8"))


def main():
    ap = argparse.ArgumentParser(description=VERSION)
    ap.add_argument("--plan", required=True); ap.add_argument("--results", default="results")
    ap.add_argument("--workers", type=int, default=0); ap.add_argument("--graph", default=os.path.join(HERE, "DZ_OPT_Graph_DualBreakout.json"))
    a = ap.parse_args()
    plan = json.load(open(a.plan, encoding="utf-8"))
    base_task, pid = plan["task"], plan.get("plan_id", "wfa")
    names = set(json.load(open(a.graph, encoding="utf-8"))["params"])
    obj = base_task.get("objective", "SharpeDaily"); sel = base_task.get("select", "plateau")
    rows = []
    for i, w in enumerate(plan["windows"], 1):
        tr = copy.deepcopy(base_task); tr.update(task_id=f"{pid}_w{i:02d}_train", start=w["train"][0], end=w["train"][1])
        s_tr = run(tr, a.results, a.workers, a.graph)
        best = s_tr["best_selected"]; ins = s_tr["metrics_best_plateau" if sel == "plateau" else "metrics_best_raw"]
        fixed = {k: v for k, v in best.items() if k in names}
        te = {"task_id": f"{pid}_w{i:02d}_test", "data": base_task["data"], "profile": base_task.get("profile", "chicago"),
              "mode": "dev", "optimize": {k: [v] for k, v in fixed.items()}, "base": fixed, "max_trials": 1,
              "objective": obj, "select": "raw", "start": w["test"][0], "end": w["test"][1]}
        for k in ("cache", "capital"):
            if k in base_task: te[k] = base_task[k]
        s_te = run(te, a.results, a.workers, a.graph); oos = s_te["metrics_best_raw"]
        rows.append({"окно": i, "обучение": f"{w['train'][0]}…{w['train'][1]}", "проверка": f"{w['test'][0]}…{w['test'][1]}",
                     f"{obj} в выборке": ins.get(obj), "прибыль в выборке": ins.get("NetProfit"),
                     f"{obj} вне выборки": oos.get(obj), "прибыль вне выборки": oos.get("NetProfit"), "сделок вне выборки": oos.get("Trades"),
                     "дефл. Шарп обучения": s_tr.get("deflated_sharpe"), "PBO обучения": s_tr.get("pbo"), "вердикт обучения": s_tr.get("verdict"),
                     "в день в выборке": (ins.get("NetProfit") or 0) / bdays(*w["train"]), "в день вне выборки": (oos.get("NetProfit") or 0) / bdays(*w["test"]),
                     "лучший набор": json.dumps(fixed, ensure_ascii=False)})
        print(f"  окно {i}: в выборке {ins.get('NetProfit')}, вне выборки {oos.get('NetProfit')}", flush=True)
    df = pd.DataFrame(rows)
    ins_d, oos_d = df["в день в выборке"].mean(), df["в день вне выборки"].mean()
    agg = {"plan_id": pid, "windows": len(df), "oos_net_total": round(float(df["прибыль вне выборки"].fillna(0).sum()), 2),
           "oos_positive_windows": int((df["прибыль вне выборки"].fillna(0) > 0).sum()),
           "walk_forward_efficiency": round(float(oos_d / ins_d), 3) if ins_d > 0 else None}
    df.to_csv(os.path.join(a.results, f"{pid}_wfa.csv"), index=False)
    json.dump({"engine": VERSION, "summary": agg, "windows": rows}, open(os.path.join(a.results, f"{pid}_wfa.json"), "w", encoding="utf-8"), ensure_ascii=False, indent=2)
    print(f"[проверка вперёд] {agg}")


if __name__ == "__main__":
    main()

# Движки оптимизации «Атласа» — руководство разработчика

**Версия:** 1.0 (2026-09-30) · **Основа:** `DZ_OPT_Engine_S021.py` v1.3, `DZ_OPT_WFA.py` v1.0, `DZ_ATLAS_Service.py` v1.0, `DZ_BT_DualBreakout_S021.py`, `DZ_OPT_Graph_DualBreakout.json`. Разделы 4 и 5 сгенерированы из графа и из реального прогона.

## 1. Контур

```
пульт (atlas_dashboard.html) ──POST /task──▶ DZ_ATLAS_Service.py ──▶ task_queue/ ──▶ running/ ──▶ done/ | failed/
                                                   │
                                                   ├─ задача ─▶ DZ_OPT_Engine_S021.py run ──▶ DZ_BT_DualBreakout_S021 (эталон)
                                                   └─ план WFA ─▶ DZ_OPT_WFA.py ──▶ оптимизатор по окнам: обучение, затем проверка
данные: DZ_DATA_Sanitizer ──▶ DZ_CERT_Data (data_certified/<СИМВОЛ>/) ──▶ оптимизатор по "data": "<СИМВОЛ>"
доверие: run_manifest.json (data_sha256) ──▶ DZ_AUDIT_Gatekeeper ◀── сертификат данных, паспорт инструмента, печать эмулятора
```

## 2. Задача `task.json`

| Ключ | Обязателен | Смысл |
|---|---|---|
| `task_id` | нет | имя папки результатов; иначе метка времени |
| `data` | да | путь к CSV **или** символ инструмента: `"MGC"` → `data_certified/MGC/MGC_M1.npz` с проверкой сертификата |
| `data_root` | нет | корень сертифицированных данных, по умолчанию `data_certified` |
| `instrument` | нет | ключ профиля в `instrument_profiles` графа: tick, usd_per_tick, комиссия |
| `mode` | да | `dev` — `optimize`; `param` — `target` + `depth`; `system` — `hypothesis` |
| `optimize` | dev | `{эталонное_имя: [значения]}` |
| `target, depth` | param | целевые параметры и глубина соседей по рёбрам графа |
| `hypothesis` | system | имя группы в `groups` графа |
| `base` | нет | фиксированные значения эталонных параметров; перекрывают профиль |
| `constraints` | нет | строки `a < b`; невозможные комбинации отбрасываются до запуска; неизвестное имя — отказ |
| `start, end` | нет | период; конец не включается |
| `objective` | нет | метрика цели, по умолчанию `SharpeDaily` |
| `max_trials` | нет | больше комбинаций — случайная выборка с зерном `seed` |
| `select` | нет | `plateau` (по умолчанию) или `raw` |
| `profile` | нет | `chicago` или `berlin` |
| `nt_template` | нет | шаблон NinjaTrader для правки лучшими значениями |

План проверки вперёд: `{"plan": "DZ-WFA-v1", "plan_id", "task": {…без периода…}, "windows": [{"train": [с, по), "test": [с, по)}]}`.

## 3. Выходы

| Файл | Содержимое |
|---|---|
| `results/<task_id>/summary.json` | итог — ключи ниже |
| `results/<task_id>/run_manifest.json` | `engine`, `task_id`, `data_sha256`, `data_file`, `data_certificate`, `period`, `instrument` — связь с сертификатом для шлюза |
| `results/<task_id>/best_trades.csv` | сделки лучшего набора |
| `results/<task_id>/trials.csv` | все испытания и метрики |
| `trials_registry.csv` | совокупный реестр испытаний проекта — основа дефлированного Шарпа |
| `results/<plan_id>_wfa.json / .csv` | проверка вперёд по окнам и в целом |
| `results/_service_status.json` | состояние очереди службы |

Ключи `summary.json` (из реального прогона): `engine`, `task_id`, `mode`, `space`, `trials_this_task`, `trials_cumulative`, `grid_total`, `objective`, `best_raw`, `best_plateau`, `best_selected`, `metrics_best_raw`, `metrics_best_plateau`, `deflated_sharpe`, `expected_max_sharpe_null`, `pbo`, `verdict`, `nt_values`, `data_sha256`, `data_file`, `data_certificate`, `period`.

**Массивы `.npz`.** Очиститель и кэш: `t, o, h, l, c, v`. Сертифицированные: `t_open, t_close, o, h, l, c, v`. Время — наносекунды UTC. Оптимизатор читает оба вида.

## 4. Параметры: эталон ↔ граф ↔ NinjaTrader

| Эталон (Python) | Свойство коммутатора | Индекс | По умолчанию | Диапазон в графе |
|---|---|---|---|---|
| `stop_ticks` | `StopLossTicks` | [E03] | 200 | [100, 150, 200, 250, 300] |
