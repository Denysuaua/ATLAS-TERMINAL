# DZ_SW_S021_15 — ревизия экспериментальных функций

**Версия:** 1.1 (2026-10-04) — добавлены Э52 и Э53 порции точечных правок; Э51 снят · **База:** коммутатор v1.16, модули по документу 14, скрипты терминала от 2026-10-04 · **Экспериментов:** 48 нумерованных (Э1–Э49, Э35 в коде нет), 11 ненумерованных настроек, 10 на стенде ПК; 48 экспериментальных настроек в меню коммутатора.

## 1. Итог ревизии

- Все 48 экспериментальных настроек коммутатора по умолчанию выключены — правило соблюдено. Включение сделано **пресетами**, не правкой умолчаний: `DZ_PRESET_EXP_ALL_S021.json` (прогон B) и `DZ_PRESET_EXP_BASE_S021.json` (прогон A, те же модули и диагностика, эксперименты выключены). Пресеты проверены против схемы меню: имена, типы, пределы; защитные свойства не трогаются.
- Цитаты учебников в коде проверены по базе: страницы верны у всех, где страница указана. Два эксперимента ссылались на CUSUM (AFML 2.5.2.1), но реализуют выдержку по времени — Э40, Э49 (и G10 без ссылки); ссылки сняты в v1.17/линии v1.3/Калман v1.4. Одно отклонение по статистике — Э41: наблюдения фильтра Гамильтона не независимы; исправлено темперированием в режиме v1.3, альтернатива — Э52.
- Четыре эксперимента в комплексный прогон не входят и идут отдельно: Э9 (стресс-исполнение), Э15 и Э16 (модуль пробоя выключен догмой), Э20 (нужен мост ПК). Две ветви-альтернативы выключены как исключающие основной механизм: K63, H13.
- Связи объявлены в `DZ_EXP_Graph_S021.json`: 30 рёбер — требует, исключает, заменяет, данные, прогрев, пара.

## 2. Как проверять «в комплексе»

1. Прогон A — пресет `EXP_BASE`, прогон B — пресет `EXP_ALL`: одни и те же дни (три дня П7 или синтетика П8), режим без ордеров [E01] вкл, график M1 (как в П7), серия исполнения [S90] = 0, пул серий [S50]–[S80] включён на умолчаниях 1/5/15/60 минут.
2. Фильтры меряются мета-разметкой Э32 [T27]: по каждому фильтру точность и полнота на всех кандидатах структуры — вето других фильтров не мешает. Разница B − A по фильтру = вклад его экспериментов.
3. Эксперименты структуры (Э37, Э38, Э42) меняют поток кандидатов — сравнивается число кандидатов и доля прибыльных по тройному барьеру.
4. Эксперименты после входа (Э3, Э4, Э13, Э43, Э44, Э47, Э48) видны только по сделкам: журнал [T17] с голосами [T18], строки ставок [T25]/[T26] и вторая реализация `DZ_ACCEPT_S021.py trades`.
5. Детерминированность: `DZ_ACCEPT_S021.py compare` по журналам [T13] двух одинаковых прогонов (Э26).
6. Предупреждение: 11 фильтров разом почти не оставляют входов — для сделочных экспериментов нужен третий прогон C: фильтры умолчания (MOD1–3, 5) плюс только эксперименты выходов, стопов и охраны.
7. Что движется в B против A — дальше по одному: протокол трёх проходов лаборатории; каждая настройка — испытание в реестре.

def session_minutes(day, sess):
    """Время открытия минуток торгового дня, UTC. Глобекс: с 17:00 Чикаго накануне до 16:00."""
    tz = sess["tz"]
    o = datetime.combine(day, dtime.fromisoformat(sess["open"]))
    c = datetime.combine(day, dtime.fromisoformat(sess["close"]))
    if sess["overnight"]:
        o -= timedelta(days=1)
    a = pd.Timestamp(o).tz_localize(tz).tz_convert("UTC")
    b = pd.Timestamp(c).tz_localize(tz).tz_convert("UTC")
    return pd.date_range(a, b, freq="1min", inclusive="left")


def news_minute(idx):
    """Минутка 08:30 по Нью-Йорку внутри сессии или −1."""
    ny = idx.tz_convert("America/New_York")
    k = np.where((ny.hour == 8) & (ny.minute == 30))[0]
    return int(k[0]) if len(k) else -1


def regimes_for_day(n, scenario, rng, markov_state):
    """Режим каждой минутки. stress — блоки по 120 мин; markov — блоки по 30 мин по цепи (Э28)."""
    if scenario in ("randomwalk", "gaps", "vspikes", "news", "calm"):
        return np.full(n, -1), markov_state
    if scenario in ("trend", "flat"):
        r = (rng.integers(0, 2) if scenario == "trend" else 2)
        return np.full(n, r), markov_state
    if scenario == "markov":
        P = np.full((5, 5), 0.1 / 4); np.fill_diagonal(P, 0.9)       # p_ii = 0,9: 10 блоков в среднем
        out, s = np.empty(n, int), markov_state if markov_state is not None else int(rng.integers(0, 5))
        for b0 in range(0, n, 30):
            out[b0:b0 + 30] = s
            s = int(rng.choice(5, p=P[s]))
        return out, s
    out = np.empty(n, int)
    for b0 in range(0, n, 120):
        out[b0:b0 + 120] = rng.choice(5, p=[0.22, 0.22, 0.26, 0.15, 0.15])
    return out, markov_state


def build_day(ins, idx, x0, scenario, rng, ou, markov_state, sigma_day):
    """Путь дня по подшагам: базовый процесс + события. Возвращает OHLCV, метки, события, конец пути."""
    n = len(idx)
    sig_min = sigma_day / math.sqrt(1380 if ins["sess"]["overnight"] else 390)
    reg, markov_state = regimes_for_day(n, scenario, rng, markov_state)
    prof = ins["sess"].get("synthetic_hour_profile")
    if prof:
        # профиль по часам биржи — из реальных данных (паспорт); среднее по дню — 1
        hrs = idx.tz_convert(ins["sess"]["tz"]).hour
        season = np.array([prof.get(str(hh), 1.0) for hh in hrs], float)
        season /= season.mean()
    else:
        m = np.arange(n) / max(1, n - 1)
        season = 0.75 + 1.0 * (2 * m - 1) ** 2                 # U-образная волатильность основной сессии акций
    drift = np.zeros(n); volm = season.copy(); kappa = np.zeros(n)
    hl = ou.get("half_life_min", 30.0)
    for code in range(5):
        k = reg == code
        if not k.any():
            continue
        if code == 0: drift[k] = 0.08
        if code == 1: drift[k] = -0.08
        if code == 2: kappa[k] = math.log(2) / hl; volm[k] *= ou.get("vol_mult", 0.7)
        if code == 3:
            pos = np.cumsum(k) / max(1, k.sum())
            volm[k] *= np.where(pos[k] < 0.8, 1.0 - 0.85 * pos[k], 2.5)
        if code == 4:
            seg = (np.arange(n) // 10) % 2
            drift[k] = np.where(seg[k] == 0, 0.15, -0.15)

    events, ev_min = [], np.zeros(n, dtype=object); ev_min[:] = ""
    volx = np.ones(n)
    add = np.zeros(n * S)
    stress = scenario in ("stress", "markov")
    # GAP на открытии
    if scenario in ("gaps",) or (stress and rng.random() < 0.5):
        J = float(rng.choice([-1, 1]) * rng.uniform(0.5, 3.0) * sigma_day * 0.3)
        add[:] += J; events.append(("GAP", 0, J)); ev_min[0] = "GAP"
    # V-прокол
    if scenario == "vspikes" or (stress and rng.random() < 0.6):
        for _ in range(1 if scenario != "vspikes" else 3):
            t0 = int(rng.integers(30, max(31, n - 60)))
            A = float(rng.choice([-1, 1]) * rng.uniform(4, 10) * sig_min * math.sqrt(30))
            m1, m2 = int(rng.integers(1, 6)), int(rng.integers(5, 31))
            a0, a1, a2 = t0 * S, (t0 + m1) * S, min(n * S, (t0 + m1 + m2) * S)
            add[a0:a1] += np.linspace(0, A, a1 - a0)
            add[a1:a2] += np.linspace(A, 0, a2 - a1)
            volx[t0:t0 + m1 + m2] *= 6
            events.append(("VSPIKE", t0, A)); ev_min[t0] = "VSPIKE"
    # Новость 08:30 Нью-Йорка
    kn = news_minute(idx)
    if kn >= 0 and (scenario == "news" or (stress and rng.random() < 0.7)):
        J = float(rng.choice([-1, 1]) * rng.uniform(5, 15) * sig_min)
        D = int(rng.integers(5, 21))
        add[kn * S:] += J
        volm[kn:kn + D] *= rng.uniform(5, 12)
        volx[kn:kn + D] *= rng.uniform(5, 20)
        events.append(("NEWS", kn, J)); ev_min[kn] = "NEWS"
    # Прокол тенью
    if stress and rng.random() < 0.5:
        t0 = int(rng.integers(10, n - 10))
        W = float(rng.choice([-1, 1]) * rng.uniform(6, 15) * sig_min)
        add[t0 * S + S // 2] += W
        events.append(("WICK", t0, W)); ev_min[t0] = (ev_min[t0] + " WICK").strip()

    # Базовый процесс по подшагам: снос, волатильность, притяжение O-U к уровню дня
    eps = rng.standard_normal(n * S)
    sig = np.repeat(sig_min * volm, S) / math.sqrt(S)
    dr = np.repeat(drift * sig_min, S) / S
    kp = np.repeat(kappa, S) / S
    x = np.empty(n * S); cur, level = 0.0, 0.0
    for i in range(n * S):
        cur += dr[i] + sig[i] * eps[i] - kp[i] * (cur - level)
        x[i] = cur
    tick = ins["tick"]
    path = x0 + x + add
    path = np.maximum(path, tick)
    path = np.round(path / tick) * tick
    pm = path.reshape(n, S)
    o, h, l, c = pm[:, 0], pm.max(1), pm.min(1), pm[:, -1]
    v = ins["synthetic_volume_per_min"] * season * volx * np.exp(rng.normal(0, 0.4, n)) * (volm / season) ** 0.8
    v = np.maximum(1, np.round(v)).astype(np.int64)
    keep = np.ones(n, bool)
    if stress:
        v[rng.random(n) < 0.002] = 0                                  # ZEROVOL
        keep &= rng.random(n) >= 0.002                                # MISSING
    lab = np.array([REG[r] if r >= 0 else "RW" for r in reg], dtype=object)
    df = pd.DataFrame({"o": o, "h": h, "l": l, "c": c, "v": v, "regime": lab, "event": ev_min}, index=idx)
    df.loc[df.v == 0, "event"] = (df.loc[df.v == 0, "event"] + " ZEROVOL").str.strip()
    dropped = int((~keep).sum())
    return df[keep], float(path[-1]), events, markov_state, dropped

    dec = max(0, -Decimal(str(tick)).normalize().as_tuple().exponent)
    return f"{x:.{dec}f}"

def calibrate_ou(a):
    """Э29: P_t − E = φ(P_{t−1} − E) + σε (AFML 13.4–13.5). Оценка по каждому дню отдельно: E — среднее дня."""
    z = np.load(a.npz)
    t = pd.to_datetime(z["t_open"] if "t_open" in z.files else z["t"], utc=True)
    c = pd.Series(z["c"], index=t)
    if a.start: c = c[c.index >= pd.Timestamp(a.start, tz="UTC")]
    if a.end: c = c[c.index < pd.Timestamp(a.end, tz="UTC")]
    xs, ys = [], []
    for _, s in c.groupby(c.index.tz_convert("America/Chicago").date):
        if len(s) < 20:
            continue
        d = s.values - s.values.mean()
        xs.append(d[:-1]); ys.append(d[1:])
    x, y = np.concatenate(xs), np.concatenate(ys)
    phi = float((x * y).sum() / (x * x).sum())
    sig = float(np.std(y - phi * x))
    step = float(np.median(np.diff(t.asi8)) / 6e10)
    hl = -math.log(2) / math.log(phi) * step if 0 < phi < 1 else float("inf")
    out = {"source": os.path.basename(a.npz), "phi": round(phi, 6), "sigma": round(sig, 6),
           "bar_minutes": step, "half_life_min": round(hl, 2), "vol_mult": 0.7, "method": "AFML 13.5, МНК по дням"}
    print(json.dumps(out, ensure_ascii=False))
    if a.save:
        json.dump(out, open(a.save, "w", encoding="utf-8"), ensure_ascii=False, indent=2)
    return out

class BarView:
    """Окно графика для модуля: только закрытые бары до текущего, только чтение."""
    __slots__ = ("k", "t", "o", "h", "l", "c", "v")

    def __init__(self, arrays, k):
        self.k = k
        for name in ("t", "o", "h", "l", "c", "v"):
            setattr(self, name, arrays[name][:k + 1])


class ExampleMomentum:
    """Образец модуля: знак приращения цены за N баров."""
    def __init__(self, N=20):
        self.N = N

    def on_bar(self, view):
        if view.k < self.N:
            return 0, 0.0
        d = view.c[-1] - view.c[-1 - self.N]
        return (1 if d > 0 else -1 if d < 0 else 0), 1.0


def make_strategy(E, module, arrays, ex):
    """Исполнитель сигналов: сигнал → ордера через API NinjaScript сертифицированного движка."""
    class SignalDriven(E.Strategy):
        params = {}

        def on_bar_update(self):
            k = self.CurrentBar
            d, c = module.on_bar(BarView(arrays, k))
            if ex.get("stop_ticks"): self.SetStopLoss(ticks=ex["stop_ticks"])
            if ex.get("target_ticks"): self.SetProfitTarget(ticks=ex["target_ticks"])
            pos, q = self.Position.side, ex.get("qty", 1)
            if d > 0 and pos <= 0: self.EnterLong(qty=q, name="SIG L")
            elif d < 0 and pos >= 0: self.EnterShort(qty=q, name="SIG S")
            elif d == 0 and pos != 0 and ex.get("exit_on_flat", False):
                (self.ExitLong if pos > 0 else self.ExitShort)(name="SIG flat")
    return SignalDriven()

def load_certified(path):

def selftest(task_path, workers):
    """Один процесс против нескольких: итоги и файлы сделок обязаны совпасть байт в байт."""
    import tempfile, filecmp
    a, b = tempfile.mkdtemp(prefix="term_w1_"), tempfile.mkdtemp(prefix="term_wn_")
    ra = run(task_path, 1, a, quiet=True)
    rb = run(task_path, max(2, workers), b, quiet=True)
    same_rows = pd.DataFrame(ra).equals(pd.DataFrame(rb))
    files = sorted(f for f in os.listdir(a) if f.endswith("_trades.csv"))

def resample(m1, minutes):
    ct = m1.index.tz_convert("America/Chicago").tz_localize(None)
    sh = pd.Timedelta(hours=17)
    st = (ct - sh).floor(f"{minutes}min") + sh
    g = pd.DataFrame({"h": m1.h.values, "l": m1.l.values, "c": m1.c.values}, index=st).groupby(level=0)
    b = pd.DataFrame({"h": g.h.max(), "l": g.l.min(), "c": g.c.last()})
    close = pd.DatetimeIndex(b.index + pd.Timedelta(minutes=minutes)).tz_localize(
        "America/Chicago", ambiguous="NaT", nonexistent="NaT").tz_convert("UTC")
    b["close_utc"] = close
    return b.dropna(subset=["close_utc"]).reset_index(drop=True)


def structure_events(b, strength, tf_tag, scope):
    """Опорные точки силы k и события пробоя закрытием — как в модуле v1.4."""
    h, l, c = b.h.values, b.l.values, b.c.values
    n, k = len(b), strength
    lastH = prevH = lastL = prevL = np.nan
    hb = lb = True; trend = 0; out = []
    lastHbar = lastLbar = -1
    for t in range(n):
        ctr = t - k
        if ctr - k >= 0:
            hc, lc = h[ctr], l[ctr]
            isH = all(hc > h[ctr - i] and hc >= h[ctr + i] for i in range(1, k + 1))
            isL = all(lc < l[ctr - i] and lc <= l[ctr + i] for i in range(1, k + 1))
            if isH and ctr != lastHbar: prevH, lastH, lastHbar, hb = lastH, hc, ctr, False
            if isL and ctr != lastLbar: prevL, lastL, lastLbar, lb = lastL, lc, ctr, False
        up = not hb and not np.isnan(lastH) and c[t] > lastH
        dn = not lb and not np.isnan(lastL) and c[t] < lastL
        if up:
            hb = True
            if trend == 0: trend = 1
            else:
                ev = "BOS" if trend > 0 else ("CHoCH+" if not np.isnan(prevH) and c[t] > prevH else "CHoCH")
                trend = 1; out.append((b.close_utc.iloc[t], 1, ev, tf_tag, scope))
        if dn:
            lb = True
            if trend == 0: trend = -1
            else:
                ev = "BOS" if trend < 0 else ("CHoCH+" if not np.isnan(prevL) and c[t] < prevL else "CHoCH")
                trend = -1; out.append((b.close_utc.iloc[t], -1, ev, tf_tag, scope))
    return out


def label(m1, events, stop_ticks, r_mult, vert, tick=0.1):
    """Тройной барьер на минутках: R-результат каждой ставки (цель +R, стоп −1, вертикаль — по закрытию)."""
    t = m1.index.asi8; o, h, l, c = m1.o.values, m1.h.values, m1.l.values, m1.c.values
    rows = []
    for ts, d, ev, tf, sc in events:
        k = np.searchsorted(t, pd.Timestamp(ts).value, side="left")    # первая минутка после закрытия бара
        if k >= len(t) - 1: continue
        e = o[k]; sl = stop_ticks * tick; pt = r_mult * sl
        up, dn = (e + pt, e - sl) if d > 0 else (e + sl, e - pt)
        res = None
        for j in range(k, min(len(t), k + vert)):
            hu, hd = h[j] >= up, l[j] <= dn
            if hu and hd: res = -1.0; break
            if hu: res = r_mult if d > 0 else -1.0; break
            if hd: res = -1.0 if d > 0 else r_mult; break
        if res is None:
            j = min(len(t) - 1, k + vert - 1); res = (c[j] - e) * d / sl
        rows.append({"time": pd.Timestamp(ts), "dir": d, "event": ev, "tf": tf, "scope": sc, "R": res, "win": res > 0})
    return pd.DataFrame(rows)


def stats(df, cost_r):
    r = df.R.values - cost_r
    n = len(r)
    if n < 10: return {"n": n}
    sr = r.mean() / r.std(); g3 = ((r - r.mean()) ** 3).mean() / r.std() ** 3; g4 = ((r - r.mean()) ** 4).mean() / r.std() ** 4
    den = 1 - g3 * sr + (g4 - 1) / 4 * sr * sr
    psr = float(norm.cdf(sr * math.sqrt(n - 1) / math.sqrt(den))) if den > 0 else float("nan")
    w = int((r > 0).sum())
    yr = df.assign(r=r).groupby(df.time.dt.year).r.mean()
    return {"n": n, "точность": round(w / n, 4), "P[p>0.5]": round(float(1 - beta.cdf(0.5, 1 + w, 1 + n - w)), 3),
            "средний R": round(float(r.mean()), 4), "PSR[0]": round(psr, 3),
            "знак по годам": "".join("+" if v > 0 else "−" for v in yr.values)}


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--npz", required=True); ap.add_argument("--start"); ap.add_argument("--end")

    if a.end: m1 = m1[m1.index < pd.Timestamp(a.end, tz="UTC")]
    lo, hi = resample(m1, a.ltf), resample(m1, a.htf)

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
==========================================================================================
DZ_WATCHDOG_Backup.py — сторож-архиватор терминала «Атлас», v1.0 (2026-09-28)

  Следит за папками NinjaTrader и хранилищами Атласа. Каждое изменение файла — новая
  версия в суточном архиве: <имя>_vNNN_ЧЧ-ММ-СС<расширение>. Ничего не перезаписывается.

  базовая копия   в начале каждых суток — все файлы как v001: день восстанавливается сам
  изменение       размер или время изменились → хеш SHA-256 → новая версия, если хеш новый
  удаление        запись в deletions_audit.log; версии в архиве остаются
  журнал          vault_manifest.jsonl — одна строка JSON на событие, только дописывается
  запасной путь   если основной диск недоступен — архив в папке пользователя

ЗАПУСК
  python DZ_WATCHDOG_Backup.py                      постоянная работа
  python DZ_WATCHDOG_Backup.py --once               один проход — для проверки
  python DZ_WATCHDOG_Backup.py --config my.json     свои папки
==========================================================================================
"""
import argparse, datetime as dt, fnmatch, hashlib, json, os, shutil, sys, time

VERSION = "DZ_WATCHDOG_Backup-v1.0 (2026-09-28)"
HOME = os.path.expanduser("~")
NT = os.path.join(HOME, "Documents", "NinjaTrader 8")
DEFAULT = {
    "vault": r"D:\NinjaTrader_Vault",
    "fallback": os.path.join(HOME, "NinjaTrader_Vault_Fallback"),
    "interval_sec": 1.5,
    "watch": {
        "Strategies": os.path.join(NT, "bin", "Custom", "Strategies"),
        "Indicators": os.path.join(NT, "bin", "Custom", "Indicators"),
        "AddOns": os.path.join(NT, "bin", "Custom", "AddOns"),
        "Templates": os.path.join(NT, "templates", "Strategy"),
    },
    "ignore": ["~*", "*.tmp", "*.suo", "*.user", "*.pdb", "*.lock", ".git", "__pycache__", "*.pyc"],
}


def sha(path):
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


class Watchdog:
    def __init__(self, cfg):
        self.cfg = cfg
        self.state = {}        # (категория, отн. путь) → (размер, mtime, sha)
        self.day = None

    # ---------- архив ----------
    def vault_root(self):
        v = self.cfg["vault"]
        try:
            os.makedirs(v, exist_ok=True)
            probe = os.path.join(v, ".probe"); open(probe, "w").close(); os.remove(probe)
            return v
        except OSError:
            os.makedirs(self.cfg["fallback"], exist_ok=True)
            return self.cfg["fallback"]

    def day_dir(self):
        return os.path.join(self.vault_root(), dt.date.today().isoformat())

    def log(self, rec):
        rec = {"time_local": dt.datetime.now().isoformat(timespec="seconds"), **rec}
        d = self.day_dir(); os.makedirs(d, exist_ok=True)
        with open(os.path.join(d, "vault_manifest.jsonl"), "a", encoding="utf-8") as f:
            f.write(json.dumps(rec, ensure_ascii=False) + "\n")

    def ignored(self, name):
        return any(fnmatch.fnmatch(name, p) for p in self.cfg["ignore"])

    def next_version(self, target_dir, stem, ext):
        n = 0
        if os.path.isdir(target_dir):
            pre = stem + "_v"
            for f in os.listdir(target_dir):
                if f.startswith(pre) and f.endswith(ext):
                    try: n = max(n, int(f[len(pre):len(pre) + 3]))
                    except ValueError: pass
        return n + 1

    def backup(self, cat, rel, src, digest, reason):
        stem, ext = os.path.splitext(os.path.basename(rel))
        tdir = os.path.join(self.day_dir(), cat, os.path.dirname(rel))
        os.makedirs(tdir, exist_ok=True)
        v = self.next_version(tdir, stem, ext)
        dst = os.path.join(tdir, f"{stem}_v{v:03d}_{dt.datetime.now():%H-%M-%S}{ext}")
        shutil.copy2(src, dst)
        self.log({"action": reason, "category": cat, "file": rel, "version": f"v{v:03d}",
                  "backup": os.path.relpath(dst, self.vault_root()), "sha256": digest,
                  "size_bytes": os.path.getsize(src)})

    # ---------- проход ----------
    def scan(self):
        seen = set()
        new_day = dt.date.today() != self.day
        if new_day:
            self.day = dt.date.today()
        for cat, root in self.cfg["watch"].items():
            if not os.path.isdir(root):
                continue
            for dirpath, dirs, files in os.walk(root):
                dirs[:] = [d for d in dirs if not self.ignored(d)]
                for f in files:
                    if self.ignored(f):
                        continue
                    p = os.path.join(dirpath, f); rel = os.path.relpath(p, root); key = (cat, rel)
                    seen.add(key)
                    try:
                        st = os.stat(p)
                    except OSError:
                        continue
                    old = self.state.get(key)
                    if old and old[0] == st.st_size and old[1] == st.st_mtime and not new_day:
                        continue                        # ничего не изменилось — хеш не нужен
                    try:
                        d = sha(p)
                    except OSError:
                        continue                        # файл занят записью — следующий проход
                    if new_day:
                        self.backup(cat, rel, p, d, "DAILY_BASELINE")
                    elif old is None:
                        self.backup(cat, rel, p, d, "FILE_ADDED")
                    elif old[2] != d:
                        self.backup(cat, rel, p, d, "FILE_CHANGED")
                    self.state[key] = (st.st_size, st.st_mtime, d)
        for key in [k for k in self.state if k not in seen]:
            cat, rel = key
            line = (f"[{dt.datetime.now():%Y-%m-%d %H:%M:%S}] УДАЛЕНИЕ | {cat} | {rel} | "
                    f"последний sha256 {self.state[key][2]}\n")
            for d in (self.vault_root(), self.day_dir()):
                os.makedirs(d, exist_ok=True)
                with open(os.path.join(d, "deletions_audit.log"), "a", encoding="utf-8") as fh:
                    fh.write(line)
            self.log({"action": "FILE_DELETED", "category": cat, "file": rel, "sha256": self.state[key][2]})
            del self.state[key]


def main():
    ap = argparse.ArgumentParser(description=VERSION)
    ap.add_argument("--config"); ap.add_argument("--once", action="store_true")
    ap.add_argument("--cycles", type=int, default=0, help="число проходов, 0 — бесконечно")
    a = ap.parse_args()
    cfg = dict(DEFAULT)
    if a.config:
        user = json.load(open(a.config, encoding="utf-8"))
        cfg.update({k: v for k, v in user.items() if k != "watch"})
        cfg["watch"] = {**DEFAULT["watch"], **user.get("watch", {})}
    w = Watchdog(cfg)
    print(f"{VERSION}\nархив: {w.vault_root()}")
    for cat, root in cfg["watch"].items():
        print(f"  {'есть' if os.path.isdir(root) else 'НЕТ '} {cat:12} {root}")
    n = 0
    while True:
        try:
            w.scan()
        except Exception as ex:                          # сторож не падает из-за одного файла
            print("ошибка прохода:", ex, file=sys.stderr)
        n += 1
        if a.once or (a.cycles and n >= a.cycles):
            break
        time.sleep(cfg["interval_sec"])


if __name__ == "__main__":
    main()

def synthetic(seed: int = 7) -> pd.DataFrame:
    rng = np.random.default_rng(seed)

    n = len(steps)

                         "price": 2000 + np.round(np.cumsum(steps), 1),

    regime = (bars["tick_num"].to_numpy() - 1) // LENGTH
    counts = np.bincount(regime, minlength=len(REGIMES))
    balanced, informed = counts[[0, 2]].sum() / 2, counts[[1, 3]].sum() / 2
    return {"баров": len(bars), "тиков в баре, среднее": bars["cum_ticks"].mean(),
            "баров на участок: сбаланс.": balanced, "информ.": informed,
            "информ./сбаланс.": informed / balanced if balanced else np.nan}

    }
    return pd.DataFrame({k: summary(v) for k, v in variants.items()}).T

"""Бары дисбаланса: тиков, объёма, денег (B04 §2.3.2.1–2.3.2.2, с.29–31, PDF 56–58).

На минутках GC неприменимо без тиков (ТЗ, п.6).

def _constraints(value: Any) -> tuple | None:
    if value is None:
        return None
    lo, hi = (float(x) for x in value)
    if not 0 < lo <= hi:
        raise ValueError("exp_num_ticks_constraints — пара (min, max), 0 < min <= max")
    return lo, hi


def _ema_ticks(history: list, num_prev_bars: int, constraints: tuple | None) -> float:
    """E0[T]: EWM-среднее (span = num_prev_bars) длин последних num_prev_bars баров, с границами."""
    recent = np.asarray(history[-num_prev_bars:], dtype=np.float64)
    value = float(ewma(recent, num_prev_bars)[-1])
    if constraints is not None:
        value = min(max(value, constraints[0]), constraints[1])
    return value


class EMAImbalanceBars(BaseImbalanceBars):
    """Бары дисбаланса с E0[T] = EWM длин прошлых баров (num_prev_bars), в границах
    exp_num_ticks_constraints. Источник: B04, с.29–31. Статус: Подтверждено по
    официальному учебнику; границы E0[T] — из интерфейса каркаса."""

    def __init__(self, metric: str, num_prev_bars: int, expected_imbalance_window: int,
                 exp_num_ticks_init: int, exp_num_ticks_constraints: Any = None, batch_size: float = 2e7,
                 analyse_thresholds: bool = False, *, min_expected_imbalance: float | None = None) -> None:
        self.num_prev_bars = int(num_prev_bars) if num_prev_bars and num_prev_bars >= 1 else None
        if self.num_prev_bars is None:
            raise ValueError("num_prev_bars — целое >= 1")
        self.exp_num_ticks_constraints = _constraints(exp_num_ticks_constraints)
        super().__init__(metric, batch_size, expected_imbalance_window, exp_num_ticks_init,
                         analyse_thresholds, min_expected_imbalance)

    def _get_exp_num_ticks(self) -> float:
        """E0[T] по длинам прошлых баров."""
        return _ema_ticks(self.num_ticks_bar, self.num_prev_bars, self.exp_num_ticks_constraints)

"""Бары серий: тиков, объёма, денег (B04 §2.3.2.3–2.3.2.4, с.31–32, PDF 58–59).

EMA — E0[T] следует за длинами прошлых баров; Const — E0[T] постоянна.
Функции get_* возвращают пару (бары, пороги по тикам).

На минутках GC неприменимо без тиков (ТЗ, п.6).
"""

from __future__ import annotations

from typing import Any

import numpy as np
import pandas as pd

from dz_afml.data_structures.base_bars import BaseRunBars
from dz_afml.util.fast_ewma import ewma

def _constraints(value: Any) -> tuple | None:
    if value is None:
        return None
    lo, hi = (float(x) for x in value)
    if not 0 < lo <= hi:
        raise ValueError("exp_num_ticks_constraints — пара (min, max), 0 < min <= max")
    return lo, hi


def _ema_ticks(history: list, num_prev_bars: int, constraints: tuple | None) -> float:
    """E0[T]: EWM-среднее (span = num_prev_bars) длин последних num_prev_bars баров, с границами."""
    recent = np.asarray(history[-num_prev_bars:], dtype=np.float64)
    value = float(ewma(recent, num_prev_bars)[-1])
    if constraints is not None:
        value = min(max(value, constraints[0]), constraints[1])
    return value


class EMARunBars(BaseRunBars):
    """Бары серий с E0[T] = EWM длин прошлых баров, в границах exp_num_ticks_constraints.
    Источник: B04, с.31–32. Статус: Подтверждено по официальному учебнику."""

    def __init__(self, metric: str, num_prev_bars: int, expected_imbalance_window: int,
                 exp_num_ticks_init: int, exp_num_ticks_constraints: Any = None, batch_size: float = 2e7,
                 analyse_thresholds: bool = False) -> None:
        self.exp_num_ticks_constraints = _constraints(exp_num_ticks_constraints)
        super().__init__(metric, batch_size, num_prev_bars, expected_imbalance_window, exp_num_ticks_init,
                         analyse_thresholds)

    def _get_exp_num_ticks(self) -> float:
        """E0[T] по длинам прошлых баров."""
        return _ema_ticks(self.num_ticks_bar, self.num_prev_bars, self.exp_num_ticks_constraints)


class ConstRunBars(BaseRunBars):
    """Бары серий с постоянным E0[T] = exp_num_ticks_init. Источник: B04, с.31–32.
    Статус: Подтверждено по официальному учебнику."""

    def __init__(self, metric: str, num_prev_bars: int, expected_imbalance_window: int,
                 exp_num_ticks_init: int, batch_size: float = 2e7, analyse_thresholds: bool = False) -> None:
        super().__init__(metric, batch_size, num_prev_bars, expected_imbalance_window, exp_num_ticks_init,
                         analyse_thresholds)

    def _get_exp_num_ticks(self) -> float:
        """E0[T] не меняется."""
        return self.thresholds["exp_num_ticks"]


def _run(bars: BaseRunBars, source: Any, verbose: bool, to_csv: bool, output_path: Any):
    out = bars.batch_run(source, verbose=verbose, to_csv=to_csv, output_path=output_path)
    return out, pd.DataFrame(bars.bars_thresholds)

def _ticks(prices, volumes=None):
    n = len(prices)
    return pd.DataFrame({"date_time": pd.date_range("2024-01-02 09:00", periods=n, freq="s"),
                         "price": np.asarray(prices, float),
                         "volume": np.ones(n) if volumes is None else np.asarray(volumes, float)})


def _random(n=3000, p_up=0.55, seed=0):
    rng = np.random.default_rng(seed)
    prices = 100 + np.round(np.cumsum(rng.choice([-0.1, 0.1], n, p=[1 - p_up, p_up])), 1)
    return _ticks(prices, rng.integers(1, 10, n))

def test_const_tick_imbalance_known_answer():
    # знаки: 0 (первый тик), затем все +1; прогрев 3 тика, окно 3
    bars, _ = get_const_tick_imbalance_bars(_ticks(100 + 0.1 * np.arange(10)), expected_imbalance_window=3,
                                            exp_num_ticks_init=3, verbose=False)
    # после 3-го тика E[b] = EWM(0,1,1) = 1,5/1,75 ≈ 0,857, порог 2,57, θ = 2 — рано; 4-й тик: θ = 3 → бар
    # затем E[b] = 1, порог 3 → бары по 3 тика
    assert bars["tick_num"].tolist() == [4, 7, 10]
    assert bars["cum_ticks"].tolist() == [4, 3, 3]


def test_const_tick_runs_known_answer():
    prices = [100, 100.1, 100.2, 100.1, 100.2, 100.3, 100.2]   # знаки 0, +, +, −, +, +, −
    bars, _ = get_const_tick_run_bars(_ticks(prices), num_prev_bars=3, expected_imbalance_window=3,
                                      exp_num_ticks_init=4, verbose=False)
    # прогрев закончен на 4-м тике (есть и покупки, и продажи): P = 2/4, порог 4·max(0,5; 0,5) = 2,
    # покупок 2 → бар; затем порог снова 2 → бар после двух покупок (тики 5–6)
    assert bars["tick_num"].tolist()[:2] == [4, 6]


def test_volume_imbalance_uses_signed_volume():
